APK 직접 설치 방법

  1. Android 기기에서 공식 GitHub 릴리스의 APK를 다운로드한 뒤 파일을 엽니다.
  2. 설치 권한 안내가 뜨면 설정에서 APK를 연 브라우저 또는 파일 관리자에만 ‘이 출처 허용’을 켭니다.
  3. 설치 화면으로 돌아가 ‘설치’를 누릅니다. 설치가 끝나면 같은 설정에서 ‘이 출처 허용’을 끌 수 있습니다.
